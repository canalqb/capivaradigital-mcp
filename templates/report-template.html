Perguntas Frequentes

Este dossiê é uma certidão oficial ou parecer jurídico?

Não. Este relatório é uma compilação de dados públicos para fins de auditoria pré-contratual (background check). Não substitui certidões oficiais, não constitui parecer jurídico e não deve ser usado como único critério de decisão.

Por que alguns processos não aparecem na lista principal?

A regra anti-homônimo exige cruzamento por documento (CPF/CNPJ). Achados apenas por nome são classificados como "Sem Documento" e ficam na seção de controle negativo. Isso evita atribuição indevida a homônimos.

O que significa CONFIRMADO, PROVÁVEL e SEM DOCUMENTO?

CONFIRMADO: documento próprio do pesquisado batendo (CPF/CNPJ no polo). PROVÁVEL: fingerprint coerente (órgão+classe+assunto+datas) sem documento próprio. SEM DOCUMENTO: controle negativo — achado por nome sem cruzamento documental, mantido apenas para auditoria.

Como funciona o ciclo PF↔PJ?

CPF do pesquisado → BrasilAPI busca CNPJs vinculados (razão social costuma embutir CPF) → para cada CNPJ, extrai CPFs mascarados do QSA → cpf_desmascarar quebra a máscara → datajud_por_cpf busca processos desses CPFs. CNPJ só entra no dossiê com âncora no CPF.

Os dados sensíveis (LGPD) estão protegidos?

Este dossiê trata apenas de dados públicos oficiais. A LGPD é observada como advertência no README do projeto: finalidade exclusiva de auditoria pré-contratual, minimização de terceiros, proibição de uso discriminatório (Lei 9.029/1995), retenção apenas pelo necessário. O MCP não bloqueia consultas por LGPD — cabe ao usuário a conformidade.
